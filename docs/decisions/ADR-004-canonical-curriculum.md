# ADR-004: Canonical Versioned Curriculum

## Status
Accepted

## Decision

Use a versioned canonical exam → subject → unit → topic → subtopic taxonomy. Source documents are mapped to this taxonomy rather than creating independent labels per document.

## Rationale

Without a canonical curriculum, the same topic fragments across PDFs and course construction becomes inconsistent.

## Consequences

- Curriculum changes are versioned.
- Aliases are separate from canonical names.
- Ambiguous mappings go to review.
- Historical content retains its original mapping/version.
